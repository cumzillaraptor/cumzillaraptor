It does not authorize host work, helper creation, helper execution, or installation. It supplies no source root, staging path, destination, runtime, release-seal input, manifest, commit, digest, caller argument, or environment interface.

The legacy candidate path is permanently excluded: `/opt/cumzillaraptors-send-runtime-candidate-v2`.
The current active runtime is permanently excluded.
