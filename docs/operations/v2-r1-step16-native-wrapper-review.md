# Step 16 native Linux host-wrapper review gate

## Status: repository-only and review-only

This package is a native C **review-only** descriptor-walk design and an unprivileged fixture harness. It is not host execution authority, a secret handoff authorization, a reviewer launch procedure, or a transport implementation. It does not access `/home/piadmin` in its tests, a host runtime, keys, RPC, Devnet, signing, sending, deployment, or any network.

The source has one fixed production target only:

```text
/home/piadmin/.config/cumzillaraptors/helius-devnet-rpc.url
```

There is no caller-controlled path, URL, config file, environment input, or secret input. Production accepts no arguments. `native_wrapper.c` contains no test-root or test-only override path: its descriptor walk always opens literal `/`, then requires root uid/gid `0/0` and exact mode `0755`.

## Fixed generated identity boundary

`tools/v2_r1_helius_handoff/native_wrapper.c` directly includes only its fixed sibling path:

```text
tools/v2_r1_helius_handoff/generated_owner_config.h
```

The repository version of that header intentionally contains an unconditional `#error`: it selects **no uid or gid for piadmin** and cannot build an executable. This is deliberate deny behavior when trusted identity configuration is absent; it occurs before any production descriptor walk or host-path access.

A future identity-header replacement is a separate, explicitly authorized generation and review gate, not part of this package. That gate must validate both facts as canonical, bounded decimal integers with grammar `0|[1-9][0-9]*`, reject whitespace, signs, prefixes, separators, expressions, macro references, and overflow, and write only reviewed literal definitions named `HELIUS_HANDOFF_GENERATED_OWNER_UID` and `HELIUS_HANDOFF_GENERATED_OWNER_GID`. It must reject a header that predefines either name before defining the literal, and must preserve the generated bytes and owner/mode evidence for independent review.

A future production build gate must verify the exact reviewed header bytes, ownership, and permissions immediately before compiling. It must use the fixed checked header path and must reject arbitrary compiler `-D` identity definitions and arbitrary `-include` paths. No build process is defined or authorized here; in particular, replacing this placeholder, selecting an identity, or compiling a usable production wrapper is outside this review-only repository package.

## Intended production descriptor contract after that later identity gate

Only after the separate gate has provided and independently verified the fixed-header literal facts, the native flow opens `/` with `O_DIRECTORY|O_NOFOLLOW|O_CLOEXEC`, requires root uid/gid `0/0` and exact mode `0755`, and retains that FD. It walks `home`, `piadmin`, `.config`, and `cumzillaraptors` only using `openat` from retained descriptors with `O_RDONLY|O_DIRECTORY|O_NOFOLLOW|O_CLOEXEC`, immediately `fstat`s each, and rejects non-directories/symlink traversal. The immediate containing directory must have the later verified numeric owner/group and exact mode `0700`.

It opens only the fixed final basename with `openat(..., O_RDONLY|O_NOFOLLOW|O_CLOEXEC)`, requires a regular file with that owner/group and exact mode `0600`, bounded-reads the held FD, and closes every acquired FD in reverse order. It validates the exact raw ASCII form:

```text
https://devnet.helius-rpc.com/?api-key=<token>
```

`<token>` is one or more `[A-Za-z0-9_-]` bytes. There is no newline, percent encoding, alternate authority/path/query, or extra byte. Neither URL nor token is emitted. Every refusal is the fixed opaque stderr line `native-wrapper-refused`.

## Deliberate transport boundary

No RPC request, reviewer invocation, or transport exists here. In particular, the existing Node reviewer cannot use argv, environment, or temporary files for a secret. A separately reviewed in-process consumer/interface is required before any later live unsigned reviewer transport may be considered. This source contains no process-launch primitive, network API/header, signer, sender, deployer, or authority-changing capability.

## Offline fixture evidence

`tests/v2-r1-step16-native-wrapper.test.mjs` compiles `tests/fixtures/v2-r1-native-wrapper-fixture.c`, a separate fixture-only translation unit with temporary unprivileged fixture root/UID/GID facts. That executable is neither included by nor deployable as `native_wrapper.c`; it exercises the same descriptor-walk properties in isolated `mkdtemp` trees: chain/final symlink refusal; parent/file mode and configured-owner refusal; malformed raw value refusal without echo; no arguments; and a final-name replacement after no-follow open that still validates held-FD bytes. Fixture-only compiler definitions never configure production source.

The suite compiles production source both normally and with the actual hostile C preprocessor inputs `-DHELIUS_HANDOFF_EXPECTED_UID=st->st_uid` and `-DHELIUS_HANDOFF_EXPECTED_GID=st->st_gid`. Both builds fail at the fixed repository placeholder; the production source neither references those caller macros nor admits a caller-selected identity path. Lexical checks require no production test-root/test-only override identifiers and retain literal `/`, uid/gid `0/0`, and mode `0755` root checks. The harness never accesses the fixed production path.

Passing this test is not authorization for secret access, host execution, identity selection, generated-header replacement, live unsigned review, RPC, signing, sending, deploying, or publication.
